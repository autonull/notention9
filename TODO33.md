# TODO.33 — The Model Authors the UI
**Scope:** make the UISG graph the *source* of production components, not only a description of them. Typed strategy props, derived component map, generated non-strategy surfaces, executable flow state, and one turn-key pipeline.
**Builds on:** TODO32 (done — 142-node graph, `GeneratedSkeleton` preview, 32/32 matrix, `uisg:check` green, `pnpm verify` L0–L3).
**Non-goals:** new dependencies (no XState, no Storybook); new visual language; new matching/ontology semantics; a second renderer or product preview route.
**Core rule:** a surface is *generated* when `pnpm uisg generate --surface <id>` emits a component that passes `pnpm check:ui`, `lint:tone`, `lint:type`, and the 32/32 matrix with no hand-written fallback.

### 2.1 Three constraints that shape the whole plan
1. **Zod strips unknown fields.** `validateGraph` parses with non-strict objects (`validate.ts:30`); `loadGraph` returns parsed graph (`cli.ts:85`). New `template`/`propsSchema` fields must land in `types.ts`, `validate.ts`, and `canonicalize.ts:19` **in the same change**, or round-trip silently drops them.
2. **Tone baseline is per-file, shrink-only.** `scripts/check-tone.mjs` fails on literal accent class growth; baseline = 261 literals in 36 files. Generated code must emit **zero** accent literals — only `var(--app-*)` tokens and scale classes — with a pre-write guard.
3. **`componentMap` is the silent failure point.** `strategyConfigs.ts:23` reads it; a moved/renamed component breaks `StrategyResolver` at runtime with no compile error. **Fix first.**

## 3. The turn-key pipeline (single command, deterministic)

```
pnpm uisg optimize [--changed] [--surface <id>...] [--apply] [--matrix] [--dry-run]
```

| Stage | Reuses | New |
| :--- | :--- | :--- |
| scan | `scanAll` (`scan.ts`) | emit `componentMap` + surface inventory |
| types | `seam-definitions.json` | emit `seamProps.ts` (one interface per role) |
| metrics | `collectMetrics` → `metrics.json` | — |
| rank | `rankItems` → `priority.json` | — |
| select | `selectFeature` + `loadContexts` | `--context <profile>` forwarding |
| generate | `generateAll` (`cli.ts:193`) | component emission, `--changed` hash gate |
| check | `uisg check` (`cli.ts:608`) | component drift + `componentMap` resolvability |
| matrix | `uisg matrix` (`cli.ts:357`) | `--profiles generated` default after cutover |

Output: JSON summary `{ scanned, typed, ranked, selected, generated, stale, checks, matrix }`; non-zero exit on failure. `--dry-run` prints without writing; `--apply` writes and records a decision.

| Tone baseline | unchanged (261) | `pnpm lint:tone` |
| Type scale | 0 violations | `pnpm lint:type` |

**Functionality won:** one command for the whole loop; typed strategy props (compile-time drift catch); derived `componentMap` (gate-time drift catch); generated non-strategy surfaces + tests; flow reducers + journeys from graph; revision-based rollback; context-profile variants without code forks.

## 7. Risks & mitigations

| Risk | Mitigation |
| :--- | :--- |
| Generated components regress UX quality | Parity test (roles/labels/testIds) + human review via `adopt` before `componentMap` switch |
| `componentMap` drift breaks strategy rendering | Phase 1 derives it from scan; Phase 1.4 gates it; parity test before switch |
| Graph field stripped by Zod | Phase 2.1 lands `types`/`validate`/`canonicalize` in one commit; round-trip test gates |
| Tone/type lint blocks generation | Pre-write guard test (0 accent literals, 0 `text-[9px]`) runs before any `--write` |
| Templates drift from graph | `generate --check` in `uisg:check`; templates are versioned in `optimize/src/uisg/templates/` |
| Flow reducer diverges from journeys | Journeys are compiled **from** the reducer (Phase 4.2), not a parallel walk |
| Bundle growth | Per-pilot delta budget; lazy strategy chunks via existing `React.lazy` |
| Half-generated tree during transition | `--surface` scoping; never bulk-write before pilot + parity + rollback proven |
