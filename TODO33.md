# TODO.33 — The Model Authors the UI
**Scope:** make the UISG graph the *source* of production components, not only a description of them. Component codegen, strategy handoff integrity, executable flow state, and one turn-key pipeline.
**Builds on:** TODO32 (done — 142-node graph, `GeneratedSkeleton` preview, 32/32 matrix, `uisg:check` green, `pnpm verify` L0–L3).
**Non-goals:** new dependencies (no XState, no Storybook — both stay open decisions, §9); new visual language; new matching/ontology semantics; a second renderer or product preview route.
**Core rule:** a surface is *generated* when `pnpm uisg generate --surface <id>` emits a component that passes `pnpm check:ui`, `lint:tone`, `lint:type`, and the 32/32 matrix with no hand-written fallback.

---
## 1. The change in one paragraph
TODO32 made the graph *truthful*: every flow it claims is executed by a registered journey. TODO33 makes the graph *generative*: `surface` nodes carry a template and a props schema derived from seams that already declare `propsShape` (`core/src/constants/seams.ts:22`), `uisg generate` emits React components plus tests, and the emitted file is registered in the strategy pipeline so `StrategyResolver` renders generated code the same way it renders hand code (`ui/src/components/StrategyResolver.tsx:78`). Hand-written components are then retired one surface at a time, each validated by the existing matrix.

### 1.1 Honest scope: what becomes generated, what stays declared
| Artifact | After TODO33 | Why |
| :--- | :--- | :--- |
| Surface components | **Generated** | Templates + seam props are declarative inputs |
| Surface tests | **Generated** | Render + a11y assertions follow from the template |
| Flow state logic | **Generated** | Steps, guards, effects, branches are already graph data |
| Flow journeys | **Generated** | Compiled from the same reducer |
| `componentMap` | **Generated** | Derived from scan + strategy configs |
| Strategy props types | **Generated** | `Seam.propsShape` + `ParamSpec` |
| Composition (`AppShell`, routes) | **Declared, hand-reviewed** | Layout intent is a design decision, not derivable from surfaces alone |
| Design tokens / theme CSS | **Declared** | Appearance is authored, not inferred from graph data |
| Copy and tone | **Declared** | Text is a product decision; generated code must not invent it |

The endpoint is not "no hand-written code". It is **no hand-written surface, test, or state machine** — with composition, tokens, and copy still authored deliberately.

### 2.1 Three constraints that shape the whole plan
1. **Zod strips unknown fields.** `validateGraph` parses nodes with non-strict objects (`optimize/src/uisg/validate.ts:30`) and `loadGraph` returns the parsed graph (`cli.ts:85`). A `template` field added only to `graph.json` disappears on load. New fields must land in `types.ts`, `validate.ts`, and `canonicalize.ts:19` **in the same change**, or `roundTripTest` silently loses them.
2. **Tone baseline is per-file and shrink-only.** `scripts/check-tone.mjs` fails when literal accent classes grow; baseline is 261 literals in 36 files. Generated components must emit **zero** accent literals — only `var(--app-*)` tokens and scale classes — or every generation changes the baseline.
3. **`componentMap` is the silent failure point.** `strategyConfigs.ts:23` reads it; a moved or renamed component breaks `StrategyResolver` at runtime with no compile error. This is the highest-risk item and gets its own phase (§4.2).

## 3. The turn-key pipeline (the deliverable that makes it operational)
One command, one report, deterministic:

```
pnpm uisg optimize [--changed] [--surface <id>...] [--apply] [--matrix] [--dry-run]
```

| Stage | Reuses | New |
| :--- | :--- | :--- |
| scan | `scanAll` (`scan.ts`) | — |
| metrics | `collectMetrics` → `doc/uisg/metrics.json` | — |
| rank | `rankItems` → `priority.json` | — |
| select | `selectFeature` + `loadContexts` | `--context <profile>` forwarding |
| generate | `generateAll` (`cli.ts:193`) | component emission, `--changed` hash gate |
| check | `uisg check` (`cli.ts:608`) | component drift in the gate |
| matrix | `uisg matrix` (`cli.ts:357`) | `--profiles generated` default after cutover |

Output: one JSON summary `{ scanned, ranked, selected, generated, stale, checks, matrix }` and a non-zero exit on any failed stage. `--dry-run` prints without writing; `--apply` writes and records a decision.

## 4. Workstreams

### 4.0 Phase A0 — Typed seam props (P0, ships first, no codegen)
*Goal: value before generation. A declarative type per seam role, applied to the 7 strategy components.*

- [ ] **A0.1** `optimize/src/uisg/seamProps.ts` → emits `ui/src/strategies/seamProps.ts` from `Seam.propsShape` + `STRATEGY_CONFIGS` (`strategyConfigs.ts:23`): one typed props map per seam role (`CaptureProps`, `ElicitProps`, `LayoutProps`).
- [ ] **A0.2** Type each strategy's `render` against its role's props (7 strategy files, mechanical). A wrong prop is now a compile error instead of a runtime blank.
- [ ] **A0.3** `uisg generate --check` compares emitted props to `seam-definitions.json`; a seam change that is not regenerated fails `uisg:check`.
- [ ] **A0.4** Test: `seamProps.test.ts` asserts each of the 7 strategy components satisfies its role's props, and that `getDefaultProps()` keys are a subset.

*Why first:* zero risk, no generated components, and it turns the largest silent-failure class (strategy props drifting from seam declarations) into a type error. Every later phase builds on these types.

### 4.1 Phase A — Component codegen (P0)
*Goal: `uisg generate --surface <id>` emits a component that replaces the hand-written one.*

- [ ] **A1 Schema**: add `template?: string`, `propsSchema?: Record<string, ParamDef>`, `generatedFrom?: string` to `UisgSurface` (`types.ts:58`); mirror in `validate.ts:30` and `NODE_FIELDS.surface` in `canonicalize.ts:19`; bump graph `version` 1 → 2 with a migration that leaves existing nodes untouched.
- [ ] **A2 Props source of truth**: backfill `surface.seam` from `componentMap` + generated `seam-definitions.json` (7 strategy components; `surface.seam` is set on 1 of 59 today). Then derive `propsSchema` from `Seam.propsShape` for that role, plus `Strategy.params` and `Strategy.getDefaultProps()`. Record the derivation (`generatedFrom: 'seam:capture-0'`).
- [ ] **A2b Unseamed surfaces**: the remaining surfaces have no seam; their props come from the template plus the capability/effect edges that render them. Mark them `generatedFrom: 'template:<shape>'` so the provenance is explicit, never implied.
- [ ] **A3 Template registry**: `optimize/src/uisg/templates/` — one template per surface *shape* (item, panel, palette, editor, status), not per surface. Templates are strings/AST fragments using `ui/src/components/ui/Primitives.tsx` only.
- [ ] **A4 Emit component + test**: `optimize/src/uisg/codegen.ts` → `generateSurface(surface, graph)` returns `{ component, test, propsSchema }`. Component is `.tsx` with typed props; test is Vitest render + a11y assertions; both written under `ui/src/components/...`. No story file (§9).
- [ ] **A5 Determinism + drift**: `uisg generate --check` compares emitted output to disk; `uisg check` gains a `components: current|stale N` line; CI fails on drift. Add a golden snapshot test (hash of all emitted output) so a template change is one reviewable diff.
- [ ] **A6 Style guard**: codegen test asserts emitted output contains **0** tone literals and **0** banned type sizes (`check-tone.mjs` regex, `check-type-scale.mjs` regex) — the guard runs before write, not after.
- [ ] **Pilots (seam-backed, one per role so three shapes are proven)**: `surface.quickcapture` (capture, shape *composer*: `input`, `onInputChange`, `onSubmit`, `extractedProps`), `surface.taginput` (elicit, shape *input*: `onInsert`, `initialKey`, `initialValue`), `surface.localmatchespanel` (layout, shape *panel*). `surface.matchitem` is second wave — it has no seam, so its props are template-derived.

### 4.2 Phase B — Handoff integrity (P0, highest risk)
*Goal: a generated component cannot silently break strategy resolution.*

- [ ] **B1 Derive `componentMap`**: emit it from `scan.ts` output (strategy id → component path/name) instead of hand-editing `ui/src/strategies/componentMap.ts:7`. Keep the file as a generated artifact with a `// GENERATED` header; hand edits are a lint failure.
- [ ] **B2 Drift gate**: `uisg check` verifies every `componentMap` entry resolves to an existing export, and that every strategy config's `componentPath` exists. This catches the TODO32 orphan class of bug at gate time.
- [ ] **B3 Rollout as a revision, not a flag**: register a generated component as a *revision candidate* through `ProfileRegistry` (revisions are the delivery record; `StrategyAdoption`/feature-flags are deprecated — `optimize/src/synthesis/adoption.ts:12`). Rollback = remove the revision; no new flag system.
- [ ] **B4 Parity test**: for each pilot, render hand-written and generated with identical props; assert equivalent DOM roles/labels/testIds. Only then switch `componentMap`.

### 4.3 Phase C — Flow → executable state (P1)
*Goal: `flow` nodes drive real component state without new dependencies.*

- [ ] **C1 Reducer generation**: `optimize/src/uisg/flowToReducer.ts` reuses the walk in `simulate.ts:34` (steps, guards, effects, `next[when]` branches) and emits `{ state, events, guards, effects }` plus a typed reducer. No XState (§9).
- [ ] **C2 Runtime hook**: `useFlowState(flowId)` in `ui/src/hooks/` loads the generated reducer; generated components consume it. Expose `window.__UISG_FLOW__` through `DevBridge` (`ui/src/dev/bridge.ts`) so `assertState`/`waitForState` work on generated flows.
- [ ] **C3 Journeys from state**: `uisg to-journey --from-flow <flowId>` emits a `JourneySpec` whose steps come from the reducer, so the matrix exercises generated state instead of a parallel model.
- [ ] **C4 Guarded/consequential parity**: guards block actions; consequential effects route through `ConfirmationModal` (`ui/src/components/ui/ConfirmationModal.tsx`) exactly as the skeleton does today.

### 4.4 Phase D — Turn-key orchestration (P1)
- [ ] **D1 `uisg optimize`**: implement §3 as one command in `cli.ts`; single worker; summary JSON; non-zero exit on failure.
- [ ] **D2 Incremental**: `--changed` hashes each surface node's canonical form (`graphHash` already exists in `canonicalize.ts`) and skips unchanged surfaces; record skipped counts. Target: < 2 s on an unchanged graph.
- [ ] **D3 Gate wiring**: add `uisg generate --check` to `uisg:check` (`cli.ts:608`) and to `pnpm verify` L1; keep `check:ui` unchanged.
- [ ] **D4 Context-aware run**: `--context <profile>` from `doc/uisg/contexts.json` (6 profiles) selects strategy + template variant; closes TODO32 remaining item 5.

### 4.5 Phase E — Replacement, cleanup, polish (P2)
- [ ] **E1 Three pilots swapped**: hand-written originals deleted; decisions recorded in `doc/uisg/decisions.jsonl` with evidence bundle IDs.
- [ ] **E2 Bulk**: `uisg generate --all --apply`; every generated surface registered; matrix re-run.
- [ ] **E3 Delete the preview**: `ui/src/dev/uisg/` removed once generated components exist; `?uisg=1` now mounts a **generated surface gallery** (extend `GeneratedSkeleton`) instead of a skeleton; no Storybook (§9).
- [ ] **E4 Docs**: `doc/uisg/README.md` (+ "graph is source of truth", codegen commands, template authoring), `optimize/README.md` (+ generated vs hand-written split), analysis record.
- [ ] **E5 Hot-path cleanup**: remove `console.log('[StrategyResolver] mergedProps:', …)` at `ui/src/components/StrategyResolver.tsx:77` — it logs every render of every strategy.
