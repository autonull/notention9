# UISG Session — 2026-11-24 (skeleton matrix)

## Decisions

- **Generated preview, not a product route.** The graph compiles to
  `ui/src/dev/uisg/GeneratedSkeleton.tsx`; it mounts at the dev entry
  (`?uisg=1`, like `?kit=1`). No parallel renderer or product route.
- **Generated artifacts are gated.** `uisg skeleton --write` emits the
  component and preview journeys; `uisg check` fails when they are stale.
- **Guards and effects are behavioral.** A guarded action stays disabled until
  its guard toggle is on; consequential effects open `ConfirmationModal` and
  fire only on confirm. Preview state is exposed as `__UISG_SKELETON__` so
  `assertState`/`waitForState` can verify both paths.
- **Matrix profiles are explicit.** `hand-built` runs a registered journey;
  `generated` runs the preview. `--profiles` selects either.
- **Grep must identify one test.** Partial `--grep` ran every test containing
  `capture-and-edit`, so bundles were overwritten and flow records were
  mislabeled. Records from that pass were dropped; the selector now matches the
  journey id at the end of the title.
