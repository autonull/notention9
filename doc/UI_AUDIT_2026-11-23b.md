# UI/UX Audit — 2026-11-23b

> Continues [2026-11-23](UI_AUDIT_2026-11-23.md). No new top-level surface.
> This pass makes values readable, first-run space intentional, and Labels
> truthful and safe.

## Verdict

The workspace was already coherent. The remaining friction came from values
that looked like storage (`work/job-request`, ISO timestamps, raw coordinates),
a centered empty state that was top-biased, and a Labels tab whose create action
did not create anything, whose delete action had no confirmation, and whose
Advanced link did nothing.

## Focus hierarchy

- Detail values are quiet; keys and operators stay visible; units, raw values,
  and the editor remain one hover or click away.
- Match cards lead with score and direction, name the matched property, then
  show gaps. `Respond` is still the single primary.
- First run has one action and one sentence, vertically balanced.
- Labels is now a working list tool: create, rename, delete with confirmation.
  The page is honest about labels belonging to notes.
