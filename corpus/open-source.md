## Community Events

Monthly contributor meetup: virtual, 1 hour, project updates, Q&A, social. All contributors welcome.

Hacktoberfest participation: labeled issues, swag, mentorship available. October 1-31.

Annual contributor summit: 3 days, workshops, planning, celebration. Travel grants available.

Weekly office hours: maintainers available for questions, PR reviews, design discussions. Discord voice.

Quarterly roadmap planning: community input on priorities, RFC discussions, feature voting.

## Project Governance

Moving to RFC-based governance: proposal process, review periods, consensus building, decision recording.

Establishing code of conduct enforcement: reporting, moderation, appeals, transparency reports.

Defining maintainer emeritus status: recognition for past contributions, reduced responsibilities.

Creating contributor license agreement: CLA bot, individual and corporate, automated checks.

Setting up security policy: vulnerability disclosure, patch release process, CVE coordination.
